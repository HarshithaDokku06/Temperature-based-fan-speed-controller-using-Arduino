**Temperature-Based Fan Speed Controller** 

This project automatically adjusts a fan's speed based on the surrounding temperature. Using an LM35 temperature sensor and an Arduino UNO, the system reads the temperature and controls the fan speed through PWM.

**Components Used**
- Arduino UNO
- LM35 temperature sensor
- DC fan
- 16×2 LCD
- Transistor and 1N4007 diode

**How It Works**
The LM35 measures the temperature and sends the readings to the Arduino. Based on the temperature, the Arduino adjusts the fan speed and displays the readings on the LCD.

**Objective**
To build a simple, cost-effective system that provides automatic temperature monitoring and fan-speed control.

**Future Improvements**
- Add IoT-based remote monitoring.
- Improve temperature control accuracy.
- Monitor temperature readings in real time.

**Domain:** Embedded Systems and IoT  
**Programming:** Arduino C/C++
